# Audio credits

No third-party audio recordings are bundled with this V2 release.

The current engine sound is generated in real time by the Web Audio API from oscillators and filtered noise. It is an original procedural approximation, not an authentic recording of a Honda CB1300, V10, or any other specific engine. Therefore, no third-party recording credits or redistribution licenses apply to the current audio.

Authentic recordings should only be added after verifying the exact source, creator, license, permitted redistribution, and attribution terms. Do not assume that a recording is reusable simply because it can be streamed online.
